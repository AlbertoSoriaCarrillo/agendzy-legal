Condiciones del servicio de Agendzy

Última actualización: 10 de septiembre de 2026

Agendzy es un proyecto de software actualmente en fase de desarrollo y piloto, promovido por Alberto Soria Carrillo e Iulian Preda Vlasceanu. Estas condiciones describen el uso del servicio durante esta fase provisional.

1. Finalidad del servicio

Agendzy facilita la atención conversacional y determinadas operaciones relacionadas con información, disponibilidad y reservas entre negocios y sus clientes a través de canales como WhatsApp.

2. Fase piloto

El servicio se encuentra en desarrollo y validación. Algunas funciones pueden estar limitadas, modificarse o no estar disponibles de forma continua. El acceso puede restringirse a negocios, números, cuentas o usuarios expresamente autorizados para pruebas.

3. Uso permitido

El usuario debe utilizar Agendzy de forma lícita y de buena fe. No está permitido intentar acceder a datos ajenos, eludir controles de seguridad, interferir con el funcionamiento del servicio, automatizar abusivamente solicitudes o utilizar el sistema para actividades ilícitas.

4. Inteligencia artificial

Agendzy puede utilizar sistemas de inteligencia artificial para interpretar mensajes y generar respuestas. La IA no es la fuente de verdad de reservas, pagos, disponibilidad u otros estados operativos. Las operaciones reales deben ser validadas por los sistemas de negocio correspondientes.

5. Disponibilidad y cambios

Durante la fase piloto no se garantiza un nivel de disponibilidad o SLA específico salvo acuerdo expreso. Podemos modificar, suspender o retirar funciones para corregir errores, mejorar seguridad o adaptar el servicio.

6. Privacidad

El tratamiento de datos personales se describe en la Política de privacidad de Agendzy.

7. Servicios de terceros

El funcionamiento de Agendzy puede depender de proveedores externos, incluidos servicios de mensajería, infraestructura y procesamiento de inteligencia artificial. La disponibilidad de esas funciones puede verse afectada por dichos proveedores.

8. Responsabilidad durante el piloto

Agendzy se ofrece en fase de prueba. Se adoptarán medidas razonables para evitar errores y pérdidas de información, pero los usuarios no deben utilizar el entorno piloto como única fuente de información crítica ni para procesos que requieran garantías contractuales no acordadas expresamente.

9. Contacto

Para cuestiones relacionadas con estas condiciones o con el proyecto durante la fase piloto: agendzy.privacy@gmail.com.

10. Cambios en estas condiciones

Estas condiciones se actualizarán a medida que evolucione el proyecto y antes del lanzamiento comercial deberán sustituirse o ampliarse por condiciones contractuales revisadas para el servicio SaaS.
